# The Mist Age - Game Profiles

A Daggerheart module for Foundry VTT that keeps campaigns and one-shots apart. Make as many profiles as you need (two campaigns, several one-shot adventures and so on). Each profile has its own:

- Fear;
- countdowns (progress and the rest);
- active party (can be turned off in the module settings).

## Switching

The GM picks the profile from the list at the top of the Fear tracker. Players see the name of the active profile there.

On a switch the module saves the current Fear, countdowns and active party into the profile being left and loads the other profile's values. Spending Fear or changing countdowns in one profile does not touch the others: switching back restores a profile exactly as it was.

## Managing profiles

The gear next to the list, or the masks button in the token controls on the left, opens the profile window. There the GM can:

- add a profile: it starts empty, with no Fear, no countdowns and no active party;
- rename a profile;
- reorder profiles;
- switch to a profile;
- remove a profile with its saved values. The active profile cannot be removed: switch to another one first.

A new world starts with two profiles, Campaign and One-shot. Activate a profile's party once and the profile remembers it.
